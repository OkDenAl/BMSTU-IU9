Лабораторная работа №3, часть 2

Эта лабораторная работа состоит из двух частей
Дадлайн по 1 и 2 частям общий - 13 апреля

Задание
Для топ 10 url из прошлой лабораторной работы построить графики:
    - количество запросов в сутки
    - доля успешных и неуспешных запросов

Анализ нужно провести с помощью ksql
для этого:
1. написать продюсер, который с некоторым интервалом посылает строки из датасета в кафку.
    по окончании файла можете начать слать строки заново
2. поднять кафку и ksql с помощью docker compose
3. поднять какой-нибудь web-ui, чтобы следить за топиками в кафке
4. выполнить анализ логов с помощью ksql
5. визуализировать результат
    - рекомендуется с помощью grafana
    - если не получилось с grafana, то выгружаете результат из кафки собственным скриптом и строите график в питоне

Требуется: 
- объяснить архитектуру полученной системы: какие данные куда перетекают, как трансформируются, какие сервисы с кем общаются и т.д.
- проверить, что результаты первой части лаборатрной работы совпадают с результатами второй части
